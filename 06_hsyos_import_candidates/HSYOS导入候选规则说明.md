# HSYOS导入候选规则说明

## 定位

本目录保存未来可能写入 HSYOS 的采购端规则候选材料。

当前状态：候选材料，不是 HSYOS 正式规则库。

## 推荐导入路径

```text
GitHub采购端规则与文档同步仓库
→ 规则审核
→ HSYOS导入候选清单
→ HSYOS正式规则库
```

## 可候选导入内容

1. ZT采购端有限受控试用规则。
2. 4项真实采购执行前缺口继承规则。
3. BOM/制板非正式BOM处理规则。
4. 供应商/采购合同类来源安全分段规则。
5. 未来安全接口保留规则。
6. 禁止读取敏感字段和原始资料规则。
7. GitHub同步安全边界规则。

## 不得直接导入内容

以下内容不得作为 HSYOS 正式规则直接导入：

- 未审核的临时判断；
- 原始资料；
- 价格、金额、付款、账号、SECURE；
- 真实采购执行结果；
- 供应商下单安排；
- 主表/总表写入内容。

## 当前建议

当前仅建议将本仓库作为 HSYOS 后续读取的采购端规则草案和文档同步源。

在 HSYOS 内正式启用前，需要另行完成：

1. 规则审核；
2. 版本编号；
3. 权限边界确认；
4. 敏感字段隔离确认；
5. 正式导入记录。

# CURRENT_EFFECTIVE_RULES

## 1. 系统定位规则

当前系统定位为 ZT采购端独立使用包 / ZT采购端小系统。

当前仅允许采购端有限受控试用，不代表公司整体大系统、HSYOS完整正式架构、ERP、供应商系统、工厂执行系统或公司总BOM系统。

## 2. 有限受控试用规则

允许：

- 采购端查看非敏感规则和文档；
- 采购端用于准备判断；
- 采购端识别缺口；
- 采购端规划下一步；
- 维护非敏感摘要模板和缺口清单。

禁止：

- 作为正式采购结论；
- 作为真实供应商安排；
- 作为下单依据；
- 写主表/总表；
- 连接系统/数据库；
- 读取价格、金额、付款、账号、SECURE。

## 3. 4项缺口继承规则

以下4项必须持续继承：

1. SKU/规格；
2. BOM/制板；
3. 包装；
4. 配件/包材。

当前状态：

- 不阻断有限受控试用；
- 阻断真实采购执行；
- 需要授权非敏感摘要值后才能进入进一步校验；
- 不得要求用户整理整表；
- 不得通过原始资料或敏感字段补齐。

## 4. BOM/制板规则

BOM/制板字段必须提取、整理、归类，但当前：

- 不写公司总BOM；
- 不生成正式BOM主库；
- 不自动推断BOM；
- 不做ERP导入；
- 缺失字段进入问题与缺口。

## 5. 敏感边界规则

供应商/采购合同类来源必须执行风险识别和安全分段。

当前禁止读取或保存具体值：

- 价格；
- 金额；
- 单价；
- 总价；
- 付款；
- 付款条件；
- 收款账号；
- 银行账号；
- 开户行；
- 发票/结算；
- `soft_unit_price_source`；
- SECURE；
- 盖章/签字页；
- 法律条款全文。

这些类别只能作为未来安全接口保留，不登记具体值。

## 6. GitHub 同步规则

本仓库只保存采购端规则、文档、非敏感摘要模板和 HSYOS 导入候选材料。

本仓库不得保存：

- 原始资料；
- 原始 PDF / 图片 / Excel 业务明细；
- SECURE；
- 价格、金额、付款、账号、银行信息；
- 系统/数据库导出；
- 主表/总表；
- 正式业务结果；
- 正式采购结论；
- 真实供应商下单安排。

## 7. 事实源规则

- G盘事实源为当前项目事实源。
- GitHub 为规则与文档同步副本。
- 后续写入 HSYOS 前必须另行审核。
- ChatGPT普通记忆不作为项目事实源。

# ZT采购端规则与文档同步仓库

本仓库用于同步 **ZT采购端小系统 / ZT采购端独立使用包** 的规则、状态、流程文档、缺口管理清单和后续 HSYOS 导入候选材料。

## 仓库定位

本仓库是采购端规则与文档同步仓库，主要用途：

1. 在 Windows 与 Mac 之间同步采购端规则和文档。
2. 为后续写入 HSYOS 系统提供规则草案、状态记录和导入候选材料。
3. 保存非敏感的阶段收口结果、限制标识、缺口清单和模板。
4. 作为 G 盘事实源的安全同步副本之一，但不替代 G 盘事实源。

## 当前系统定位

当前系统统一定位为：

- ZT采购端独立使用包；
- ZT采购端小系统；
- 采购端有限受控试用规则与文档体系。

当前系统不是：

- 公司临时使用系统；
- 公司整体大系统；
- HSYOS完整正式架构；
- ERP系统；
- 公司总BOM系统；
- 供应商系统；
- 工厂执行系统。

## 当前状态

当前有效结论：

- 允许继续 ZT采购端有限受控试用；
- 禁止真实采购执行；
- 禁止正式采购结论；
- 禁止真实供应商下单安排；
- 正式第8试运行继续冻结；
- 4项真实采购执行前缺口继续保留：SKU/规格、BOM/制板、包装、配件/包材。

## 与 HSYOS 的关系

本仓库中的规则和文档后续可作为 HSYOS 的导入候选材料。

建议路径：

```text
采购端规则草案层
→ HSYOS规则审核层
→ HSYOS正式规则库
```

本仓库内容不得直接等同于 HSYOS 正式规则库，除非后续经过单独审核、导入和版本确认。

## 严格禁止上传内容

本仓库禁止保存以下内容：

- 原始订单资料；
- 原始 PDF / 图片 / Excel 业务明细；
- SECURE 目录或 SECURE 内容；
- 价格、金额、付款、付款条件；
- 收款账号、银行账号、开户行、收款行；
- `soft_unit_price_source`；
- 系统/数据库导出；
- 主表/总表；
- 正式业务结果；
- 正式采购结论；
- 真实供应商下单安排。

## 目录说明

```text

05_templates/                     非敏感摘要值接收模板

```

## 当前使用原则

1. GitHub 只保存采购端规则、文档、模板和非敏感摘要级材料。
2. G盘仍是当前项目事实源。
3. ChatGPT普通记忆不作为项目事实源。
4. 所有后续规则更新应先明确边界，再同步到本仓库。
5. 未带限制标识的输出不得被当作正式采购结果使用。
